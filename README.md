Aplikacja służy do wyświetlania koktajli i ich składników. Została wykonana w Android Studio (w najnowszej wersji Panda 2) w języku Kotlin. Z powodu problemów technicznych, aplikacja była testowana tylko na Androidzie 16.0

Aplikacja zawiera:
- listę koktajli oraz składników;
- wyszukiwanie;
- filtrację;
- odświeżanie;
- ustawianie trybu jasnego/ciemnego
