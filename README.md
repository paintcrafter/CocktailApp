Aplikacja służy do wyświetlania koktajli i ich składników. Została wykonana w Android Studio (w najnowszej wersji Panda 2) z zestawem bibliotek Jetpack Compose w języku Kotlin. Z powodu problemów technicznych, aplikacja była testowana tylko na Androidzie 16.

Aplikacja zawiera:
- listę koktajli oraz składników;
- wyszukiwanie;
- filtrację;
- odświeżanie;
- ustawianie trybu jasnego/ciemnego;
- opcję polubienia.
